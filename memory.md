# Soft Strange Drawing

Purpose: Quest mixed reality reference images for freehand physical drawing.

Architecture: Unity 6000.3.11f1; Android ARM64 IL2CPP; OpenXR 1.16.1, XR Hands 1.7.2, Unity OpenXR Meta 2.4.0. AR Foundation camera manager supplies passthrough. ProjectBuilder configures the project, generates the initial scene, and builds the APK. DrawingApp hosts the service registry and plugins; ImageLibraryService owns references and imports; StudioView builds the Unity world-space canvas UI; HandInput adapts tracked joints; ReferenceSheet owns manipulation; VectorOutlineService traces and renders cubic Bezier strokes; DiagnosticsService records state; UploadServer accepts bounded loopback uploads and commands in review/desktop builds only; Reference.shader preserves alpha and extracts edges. DesktopInputPlugin and HouseSimulationPlugin provide local studio behavior.

Interaction: thumb/index midpoint origin; wrist-forward direction with 75 ms smoothing, independent of finger curl; pinch entry scales with hand size within 24–30 mm, release is 14 mm wider, with rearming and brief debounce. System gestures and focus loss cancel interaction and mute audio. Hand tracking with controller trigger/grip fallback. Menu stays upright at 0.8 m and follows large yaw changes gently; freeze while pinching. Home has Start drawing and Choose outline, drawing dock has Outlines, Lock/Unlock and Palette. Ink/Grid/Studio are contextual drawers. Grid is independent and remains visible/placed through reference lock, image changes and app recenter. White fully transparent outline assets are default; color, opacity, curve width and dotted strokes are runtime controls. Curve processing is automatic with a 2,048-path bound; if an imported image exceeds it, preserve the full solid raster rather than showing truncated curves. Dotted defaults use closer spacing and saved preferences. Decorative model motion and original soundscape have quiet defaults and advanced controls.

Durable scope: 60 filtered AI illustrations plus 60 bundled model subjects with 120 matched side/top views and 60 original stylized Blender models and native file import, with USB-forwarded upload and developer commands, no account/backend, one image at a time, PNG/JPEG, 12 MB, 4096 pixels per axis, 100 saved images. Images persist; placement is session-local until spatial anchors are separately authorized. Runtime joint skeleton is a diagnostic visualization, not a custom skinned hand avatar.

Validation convention: import/build/install/log evidence does not prove headset interaction acceptance. Keep current results in docs/validation.md. Quest USB forwarding uses local 8790, desktop uses 8787. Rebuild review APKs through tools/headset.py build and signed non-development Quest releases through tools/headset.py build --release (requires the existing protected local signing identity); install/launch/connect for the review APK through tools/headset.py install; preserve app data with adb install -r.

Runtime conventions: preserve primitive mesh/collider types through Assets/SoftStrange/link.xml when using CreatePrimitive under IL2CPP stripping. Generated UI children must set center anchors/pivots explicitly. tools/headset.py validate uses the same bundled ADB as Unity and writes bounded device validation reports; use device epoch timestamps for logcat time filtering.

UI input ownership: physical hand and DesktopInputPlugin presses exclusively invoke PinchButton; do not add a second InputSystemUIInputModule to the same canvases, which double-fires toggles on mouse release.

XR build configuration: one canonical OpenXR Package Settings asset is referenced by EditorBuildSettings. Unreferenced duplicates can cause MetaQuest build hooks to find multiple feature assets and return null; retain backups outside Assets. Desktop build isolation removes unsupported XR settings from player preloaded assets after package preprocessors. Studio scenes remove mobile AR components rather than serializing disabled unsupported scripts.

Store boundary: non-development candidate disables the developer endpoint and automatic pose recording; manifest removes raw-camera permissions and enables contextual passthrough startup. Quest builds pin target SDK 34 with minimum 32; the manifest uses automatic install location and excludes the launching activity from recents. tools/sign_release.py signs the non-development intermediate candidate as builds/SoftStrangeDrawing-QuestRelease.apk with APK v2/v3 signatures. The release identity is outside the repository in ~/.local/share/SoftStrangeDrawing/signing; never commit or print its password, replace its key, or remove an installed test-signed app without approval because uninstalling deletes local data. Back up the entire private signing folder securely. Test signing does not qualify the package for production. Public privacy/support details, production identity, final device acceptance and Meta review remain explicit gates.

User preference: do not use the file explorer. Use app upload/API tooling for automated image transfer and testing.

Reference-art preference: show preserved AI illustrations through a cleanup filter, with pure white recolorable ink and transparent interior/background. Keep AI art distinct from Blender-derived Side / top views; never relabel a three-quarter illustration as an orthographic view. tools/process_reference_library.py rebuilds all 60 from immutable art/source originals and records filter settings, hashes and alpha checks.

Delivery builds: use tools/build_delivery.py to isolate Unity processes per target. AR Foundation temporarily relocates XR simulation settings; stale identical unreferenced copies can block stripping. Archive them outside Assets with their metadata, preserve canonical Resources settings, and never delete differing or referenced settings.

Restore Quest settings after builds. Freehand support requires a genuine runtime provider; physical Frame acceptance remains separate.
